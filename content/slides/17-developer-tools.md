### Important Notes

While it builds and writes code incredibly well:

- AI code has some really odd decisions
- **Key technique**: If you can code well (especially backend), interrupt and correct before it goes off rails
- Use techniques to generate non-complete-shit code
- Then have AI correct it to reach quality code

### The Workflow

1. Let Claude Code work autonomously
2. **Monitor actively** - if you see crap while it's working, interrupt immediately
3. Correct it before it goes off rails
4. Have it refactor and improve

This is how you go from AI-generated code to production-quality code efficiently.
