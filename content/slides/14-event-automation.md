# Automate Event-Based Tasks

## The Problem

Repeating tasks in administration can take lots of time:

- Event-based tasks
- "Cronjobs" that have to be done at a certain date
- Once they reach critical mass, you usually hire a person

## The Solution

**Event-based agentic automation** can help this person, or for simpler/smaller scale, replace them.

## Example: Hiring Process Automation

### Traditional (Manual) Process:

1. Define open positions
2. Candidate sends application via form
3. **You** read and assign to HR/team lead
4. **They** read, assess, and resolve:
   - Reject
   - Set interview
   - Assessment → Reject or Tech interview
5. Each step requires **human input**

### AI-Powered Process:

1. Email comes in and is **parsed**
2. CV and content **compared to rules** for open position
3. **Compliance score** calculated → if high enough, move on
4. **Report computed** based on:
   - Public GitHub repos\*
   - LinkedIn posts\*
   - Other data
   - CV + email content
   - Match with position
5. Move to **technical assignment**
6. After solution received:
   - Code **reviewed by AI**
   - **Report generated**
   - Technical interview set
7. Team lead does **one interview instead of two** with **two reports** to guide questions

### Result: More focused human time, better candidate assessment
